# Reference Implementation Notes

The actual, working code lives in
[`../sdk/reference-impl/`](../sdk/reference-impl/), per the
distinction the repository root README draws between `sdk/`
(implementation code) and this directory (implementation-adjacent
notes and guidance tied to the ONP-9000 series).

pointer. As the Reference series (`specs/9000-*.md` through
`specs/9004-*.md`) accumulates real-world implementation experience —
beyond what a single minimal reference implementation demonstrates —
